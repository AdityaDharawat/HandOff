# HandOff visual system

A repository workbench for developers inheriting unfamiliar code. The overview
uses a quiet light canvas, a narrow index, and a prominent evidence map. Dark
architectural ink and one precise teal identify navigable evidence.

The runtime token owner is `src/handoff/dashboard/style.css`. Canvas #f5f6f2,
surface #ffffff, ink #19251f, subdued #596760, accent #006c55, line #dce3dc.
Use Aptos or system sans for interface text and Consolas or system mono for
paths and counts. Thin boundaries and compact section titles establish hierarchy.
The graph is the signature element. Sources and findings use the same row and
status conventions across screens. Keep reduced motion and keyboard focus visible.
