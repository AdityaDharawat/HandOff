# Working on HandOff

Use Python 3.11 or newer. Run Ruff and pytest before submitting changes. Keep
scanning static and offline. Tie every generated finding to an evidence record.
Never place source snippets, raw Git messages, logs, or credential values in
published reports. Make skill edits in src/handoff/skill_manifest.md and sync
the checked-in copies with scripts/sync_skills.py.
