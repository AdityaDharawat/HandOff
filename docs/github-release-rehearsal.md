# GitHub release rehearsal

The hosted rehearsal has yet to run. The workflow checks staged source,
then verifies the source archive, wheel and VSIX. SHA-256 checks cover each
artifact. A dispatch with publishing disabled skips release creation.
An authorized non-public repository, approved version tag and independent
review are required for the rehearsal.

See [owner setup](private-exclusion-policy.md) and the
[release guide](releasing.md). Keep configuration evidence and run logs private.
