## HandOff 0.1.0

- Analyze a local repository and browse architecture, features, evidence, and risks in VS Code.
- Generate evidence-linked developer and agent handovers and export an offline dashboard.
- Install the VSIX from this release with **Extensions → Install from VSIX…**.
  Requires desktop VS Code 1.95+ and Python 3.11+ with venv and pip.
- On first analysis, approve engine setup. Dependency installation may use
  your Python package index. Repository analysis, report generation, and
  dashboard export run locally and offline.

See docs/installation.md in the source tree for manual updates and rollback.
