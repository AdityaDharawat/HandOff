# Visual platform baseline

The existing CLI calls core capture, which builds an evidence snapshot from bounded
filesystem and Git scans. Intelligence classifies observations. Reports share
a renderer and managed publication preserves manual notes. Validation checks
digests, references, and managed content. The Windows baseline produced 52 passed
and one symlink skip. Ruff passed.

The existing reports expose a large evidence index and mix progress, risks and
next actions. A reader needs a short conclusion, a source map and distinct
verification information before the full records. Feature scope and runtime
behavior remain unknown when static evidence is insufficient.

Keep scanner, storage, validation and report transactions in Python. Add a
versioned JSON subprocess protocol and a shared dashboard asset bundle consumed
by VS Code and offline exports. Ship a bundled engine wheel, create a dedicated
extension-managed environment from an installed Python, and explain setup when
Python or dependencies are unavailable. No project commands run. Guard writes
with confirmation and existing managed-file protections. Verify engine and
publication first, then dashboard flow, extension compilation and packaging,
then a real repository when available.

React Flow adds a React runtime and Cytoscape adds an independent layout/rendering
dependency. The initial graph is a capped static-import projection with a stable
layout, keyboard focus, pan and zoom, shared with SVG export. Native SVG avoids
another runtime and keeps the offline build self-contained.
